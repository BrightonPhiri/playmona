Seed Determinism Test

Renders every race game's questions twice under the same seed and compares them. A failure here means devices in a room would see different questions.

Scope: this diffs rendered text, so it covers question content, option wording and option order. It does not observe values produced later by timers (such as Quick Tap's GET READY delay). Those are deterministic by construction — they call FF._rand(), so the same seed and the same call order give the same result on every device.
