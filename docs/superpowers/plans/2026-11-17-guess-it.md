# Guess It! Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove nine old games, and replace seven "Guess the…" games with one premium game, Guess It!, with nine topics plus Mix.

**Architecture:** New `js/games/guessIt.js` owns the topic picker, settings, a shared photo-round engine, recap and room fields; pure rules live on `FF.GuessIt`. Flags reuses Guess the Country's engine, which stops registering its own game and exposes `setupScreen`/`play`. New photo data in `js/data/guessIt.js`; Animals keep `js/data/animals.js`.

**Tech Stack:** Classic browser scripts on `window.FF` (no modules), node test harness `tools/test/harness.js` (`node tools/test/one.js <file>`; all: `node tools/test/run.js`), PHP lists in `api/lib`, Python/Pillow art cutter.

**Spec:** `docs/superpowers/specs/2026-11-17-guess-it-design.md`

## Global Constraints

- Game id `guessIt`, name `Guess It!`; topics in order: `mix, animals, flags, food, landmarks, objects, sports, vehicles, jobs, instruments`.
- Item counts: food 30, landmarks 24, objects 30, sports 18, vehicles 24, jobs 24, instruments 24.
- Photos at `assets/images/games/guessIt/<topic>/<id>.webp`, 640 px square, ≤ 90 KB.
- Level answers: easy 4, normal 4, hard 6, expert spelled. Times: 5/8/12/0 s, standard 8. Expert +6 s. Flash 1.5 s, +25.
- Points: 100 × {easy 1, normal 1.5, hard 2, expert 2} + round(50 × timeLeft/time) + 50 per 3-streak + flash 25 + typed 50; rooms: 100 × difficulty + 50 inside 3000 ms.
- Standard = any topic, normal, 8 s, twist none, default length. Rooms: no Expert, max 6 options.
- Colours only from `css/tokens.css`; screens via `FF.GameUI`/`FF.UI`; classes `.gi-*` in `css/games.css`; sentence case; strings via `FF.t`; no answer in alt/aria.
- All dealing through `FF.Random`/seeded rng, never `Math.random` or localStorage, while dealing.
- Do not push to `main` (it deploys). Ship only when all 29 sheets are cut.

## Review Focus

- A topic with fewer items than the requested rounds: deal must cap rounds, not repeat or crash (test in Task 3).
- Expert with a long name (e.g. "Christ the Redeemer", 17 letters): spell an `aka` ≤ 16 letters or keep tiles ≤ `FF.SpellTiles.MAX_TILES` (test in Task 3).
- Mix: lookalike answers must come from the same topic, never "Pizza" as a decoy for a violin (test in Task 3).
- Leaving mid-round (Back key / "Leave this game?") during Zoom out or Flash: timers cleared, no late callback writes to a gone screen (guard with `stillShown(api)` in Task 5).
- Old saved setups / challenge links naming removed ids (`guessFood`, …): open as `guessIt` with that topic instead of a dead game (alias map in Task 6).
