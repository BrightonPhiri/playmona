**Goal:** A new game, Logo Rush (id `logoRush`): see a brand's symbol, name the brand by picking, spelling with tiles, typing, or saying it out loud; solo, one-device groups and server-refereed online Race.

**Architecture:** Brand data in `js/data/logos.js`; logo files downloaded once into `assets/images/games/logoRush/` by `tools/logos/fetch.js`. Pure rules in `js/logorush/rules.js` shared by the screen, the referee and tests. The screen `js/games/logoRush.js` copies GeoSpin's frame/setup/play/reveal/recap structure and reuses GeoSpin's `letterBoard` / `choiceBoard`. Online play copies GeoSpin's referee pattern (`rooms/<code>/lr`, `lrInbox`, `logorushRuns`, `logorushState`, `api/lib/LogoRush.php`).

**Tech Stack:** ES5 classic scripts on `window.FF`, no build step; Node test harness (`tools/test/harness.js`: `loadFF`, `test`, `assert`, `assertEqual`; one file with `node tools/test/one.js <file>`); PHP 8 API with `tools/api/test.php`; Firebase RTDB rules in `database.rules.json`.

## Global Constraints

- Game id `logoRush`, name "Logo Rush", category `quiz`. Classes prefixed `lr-`, tokens `--lr-*` that re-point `--gs-*` (as Letter Rush does in `css/games.css`).
- The symbol shown in play never contains the brand's name. The full logo (with name) is only shown at the reveal.
- Answer styles (`MODES`): `tiles` (standard), `choice`, `type` (labelled Expert), `say` (one device, `everyone` mode only). Rooms allow `tiles` and `choice` only.
- Levels: `easy` (tier 1), `normal` (tiers 1–2, standard), `hard` (tiers 2–3, `alike` decoys). Choices follow the level: 4 / 6 / 8 (my call, same as GeoSpin).
- Categories: `tech`, `social`, `food`, `fashion`, `cars`, `shops`, `fun`, `travel`, `money`, `football`; plus the `africa` filter (a brand flag, not a category); `mixed` = all. Labels: Tech & apps, Social & media, Food & drink, Fashion & sportswear, Cars & motoring, Shops & retail, Entertainment & games, Travel & airlines, Banks & money, Football clubs, African brands.
- Time per logo (`TIMES`): `quick` / `normal` / `relaxed` / `none` = choice 5/8/12 s, tiles and type 12/20/30 s (my call: spelling needs longer than picking); type gets +6 s. Timeout = wrong. Rooms never use `none`.
- Twists: `none`, `zoom` (starts at 4× on a seeded point, pulls back to 1× over the round), `flash` (symbol hides after 1500 ms), `grey` (CSS `grayscale(1) contrast(1.1)`). Rounds 10 / 15 / 20.
- Points: base easy 100 / normal 200 / hard 300; speed bonus up to 50 (zoom: up to 100); `type` +50; `flash` +25; `grey` +25. Wrong or late: 0.
- `STANDARD = { level:'normal', cats:'mixed', mode:'tiles', time:'normal', twist:'none', rounds:10 }`. Daily, challenge and rooms start from STANDARD; only STANDARD level/cats/mode/time/twist count for leaderboards (`customRules` otherwise).
- Deal with the seed (`R.rng(R.hash(...))`), never `Math.random`.
- British spelling in all copy. Facts: one line, ≤ 110 chars, true, no brand name in a way that spoils a later round.
- Logo files: SVG preferred, WebP fallback; no `<script>`, `on*=` attributes, `<foreignObject>`, external `href`; symbol ≤ 60 KB, full ≤ 120 KB.
- Colours from `css/tokens.css`, passing `node tools/contrast-check.js`.
- `lrInbox` rule hand-added to `database.rules.json` after `cwInbox` (gen-rules.js would drop it). Match ids `newId('l')`.
- Backspace is the app's global back key: every key handler in the capture phase with `stopPropagation`.

## Review Focus

1. **Names that look alike or share words** (Apple / Apple Music, Pepsi / Korean Air, Puma / Jaguar, Man City / Man United): typing another brand's name, or a guess as close to another brand, is wrong and `near` names that brand. Test in Task 3.
2. **Names with marks, digits and accents** (Coca-Cola, McDonald's, 7-Eleven, H&M, Nestlé, 3M, Mercedes-Benz): spellable from their own tiles, marks laid out for the player, typed `mcdonalds` / `nestle` / `coca cola` accepted. Tests in Tasks 1 and 3.
3. **A small pool** (Football + Easy, or African + Hard, with 20 rounds): the pool widens like GeoSpin's, no brand repeats until all are used, and choice mode still finds enough distinct names. Test in Task 3.
4. **A logo that is slow or fails to load:** the clock starts only once the symbol is shown (wait at most 3 s); a failed image swaps in the next unused brand and the round is not scored. Pure helper `R.nextUnused(ids, used)` tested in Task 3; browser check in Task 4.
5. **The same seed on two devices** (daily, challenge): identical brands, tiles, choices and zoom points, whatever each device's saved setup. Test in Task 3.
