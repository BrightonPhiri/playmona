> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new game, Say What? (id `sayWhat`): a well-known saying appears with one word (or, on Hard, two) missing, and players fill the gap with letter tiles (default) or choices. Solo, Turns on one device, and server-refereed online Race with crew players.

**Architecture:** Sayings in `js/data/sayings.js`. Pure rules in `js/saywhat/rules.js` (deal with the no-repeat rule, tiles, choices, checking, points, streak) shared by the screen, the referee, the crew brain and the tests. Online copies Logo Rush's referee pattern (`rooms/<code>/sw`, `swInbox`, `saywhatRuns`, `saywhatState`, `api/lib/SayWhat.php`) and What's Missing's crew brain.

## Global Constraints

- Game id `sayWhat`, name "Say What?", category `word`. CSS classes `sw-`, tokens `--sw-*` in `css/tokens.css`. Match ids `newId('y')` (`w` is WordFlow's; `y` is free as of 3e909a1b).
- Packs (`PACKS`): `everyday` "Everyday", `african` "African proverbs", `bible` "Bible", `kids` "Kids"; `mixed` = all. Targets: everyday ≈ 140, african ≈ 60, bible ≈ 50, kids ≈ 50 (±10 each).
- Levels: `easy` (easy rows), `normal` (easy + normal, standard), `hard` (normal + hard, two-gap items possible). Kids rows are all `easy` and **play at every level**.
- Answer (`ANSWERS`): `tiles` (standard), `choice`. Choices: 4 options.
- Tiles always dealt with `FF.SpellTiles.deal(target, rand, { difficulty: 'hard', related: decoyWords })` (2× the letters, capped at 30 by SpellTiles).
- Time per saying (`TIMES`): `quick` / `normal` / `relaxed` / `none` = tiles 15 / 25 / 40 s, choice 8 / 12 / 18 s; two-gap +10 s. Timeout = wrong. Rooms never use `none`.
- Sayings per round (`ROUNDS`): 10 / 15 / 20, standard 10. In Turns it is per player. A round is capped at the pool's saying count.
- Points: base 100 × level weight of the saying (easy 1, normal 2, hard 3); speed up to +50 linear over the limit (none with `none`); two-gap +50; streak bonus from the 3rd right answer in a row: +25, +50, +75, then +100 each. Wrong / timeout = 0 and resets the streak.
- `STANDARD = { level:'normal', packs:'mixed', answer:'tiles', time:'normal', rounds:10 }`. Daily, challenge and rooms start from STANDARD; only STANDARD counts for leaderboards (`customRules` otherwise); `choice` never counts.
- Rooms: `answer` tiles/choice, `level` normal/hard, `packs` always `'mixed'`, `time` ≠ `none`, `rounds` 10/15/20.
- No-repeat: one saying at most once per round, every mode. History `FF.Storage` key `sayWhat:seen` = `{ "<id>#<gap>": 1 }`, read/written by Solo and Turns only; daily, challenge and online never touch it.
- Looks: `bubble` (default) and `chalk`, saved per device in `sayWhat:look`; setup saved in `sayWhat:setup` (`{ v:1, … }`).
- Deal with seeds (`R.rng(R.hash(...))`), never `Math.random`.
- British spelling in copy. Meanings: one plain line ≤ 80 chars, ending with `.`, child-friendly.
- Colours from `css/tokens.css`, passing `node tools/contrast-check.js`.
- `swInbox` rule hand-added to `database.rules.json` after `skbInbox` (gen-rules.js would drop it).
- Backspace is the app's global back key: every key handler in the capture phase with `stopPropagation` (SpellTiles already does this).

## Review Focus

1. **Turns with many players on a small pack** (4 players × 20 on Kids): the round is capped at the pool size and still has no saying twice; setup says so. Test in Task 2.
2. **History across many rounds** on one pack: one-gap sayings never return until the pool is spent, multi-gap sayings return with an unused gap, and when the pool runs dry it resets instead of dealing a short round. Test in Task 2.
3. **Gap words with apostrophes, hyphens or capitals** ("don't", "well-being", "Rome", "God"): spellable from their own tiles, marks laid out, case ignored when checking. Tests in Tasks 1 and 2.
4. **An `also` word or a typo near another gap word**: `also` accepted, decoys rejected, a decoy never equals the answer or an `also`. Test in Task 2.
5. **Same seed on two devices** (daily, challenge, online): identical sayings, gaps, tiles and choices whatever each device's history or saved setup. Test in Task 2.

### Task 2: Pure rules (`js/saywhat/rules.js`)

**Files:**
- Create: `js/saywhat/rules.js`
- Test: `tools/test/sayWhat.test.js` (rules section; also load `js/spellTiles.js`)

**Interfaces:**
- Produces `FF.SayWhatRules` (`R`) with constants `PACKS`, `LEVELS`, `WEIGHT = { easy:1, normal:2, hard:3 }`, `ANSWERS = ['tiles','choice']`, `TIMES`, `SECONDS = { tiles:{quick:15,normal:25,relaxed:40}, choice:{quick:8,normal:12,relaxed:18} }`, `TWO_EXTRA = 10`, `ROUNDS = [10,15,20]`, `STANDARD`, `MIN_PLAYERS = 2`, `MAX_PLAYERS = 8`, `REVEAL_MS = 5000`, `MAX_TILES = 30`.
- `hash`, `rng`, `shuffle`: copy from `js/logorush/rules.js:130-150`.
- `sanitize(raw) -> settings`, `sanitizeRoom(raw)` (forces room rules from Global Constraints), `isStandard(s)`.
- `items(settings) -> [item]` with `item = { key:'<id>#<gap>' or '<id>#<a>+<b>', id, gaps:[word], level }`: every single gap of every row in the pool, plus `two` pairs when level is `hard`. Pool = rows whose pack is chosen and whose level is in the level's set (kids rows always).
- `levelCounts(packs) -> { easy, normal, hard }` (sayings, not items) for the setup buttons.
- `deal(settings, seed, count, seen?) -> { items:[item], reset:boolean, capped:boolean }`. Algorithm (not determined by the tests alone):
  ```
  rand = rng(hash('deal|' + seed)); pool = items(settings); n = min(count, distinct ids in pool)
  fresh = pool not in seen (a two-gap item is fresh only if both single keys are unseen)
  if distinct ids in fresh < n: reset = true; fresh = pool
  order fresh by shuffle(rand); prefer single-gap items 3:1 over two-gap on hard (pick a two-gap item when rand() < 0.25 and one is available)
  take items one by one, skipping any whose id is already taken, until n
  capped = n < count
  ```
  With `seen` absent, history is ignored (daily, challenge, online).
- `markSeen(seen, items, settings) -> seen` (adds each single key; two-gap items add both; when `reset` was true the caller passes `{}` first).
- `roundAt(settings, seed, k, item) -> { k, id, gaps, words:[{ text, gap?:index }], target, cells, letters, tiles, choices?, seconds, meaning }`. `target` is the gap word or `'A B'` for two gaps. Tiles from `FF.SpellTiles.deal(target, rand, { difficulty:'hard', related: decoys })` with `rand = rng(hash('tiles|'+seed+'|'+k))`; choices (4 strings) with `rng(hash('choice|'+seed+'|'+k))`: the answer + 3 decoys; for two gaps, pairs `'decoyA decoyB'` mixing each gap's decoys with the right other word (at most one pair right).
- `check(round, text) -> { ok, near }`: each gap via `FF.AnswerMatch.create` over `[gap].concat(also)` vs that row's decoys; two gaps split `text` on whitespace into two words, both must pass.
- `secondsFor(settings, round) -> number|null`; `points({ level, ok, ms, secs, two, streak }) -> { base, speed, two, streak, total }` where `streak` is the count of right answers in a row **including this one**.
