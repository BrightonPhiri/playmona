# Charades rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain Charades screen with a team party game: fast 60 s turns, 12 themed decks, optional twists, a recap after every turn, signals sheet, and a theatre-spotlight stage in GeoSpin's arcade style.

**Architecture:** Pure rules in `js/charades/rules.js` (`FF.CharadesRules`, tested in Node), cards in `js/data/charadesDecks.js` (`FF.data.charadesDecks`), and the screens in `js/games/charades.js`. Theatre styles are a `.ch-` block in `css/games.css`. The old Charades block in `creativeGames.js` goes away. Don't Say It and Visual Charades keep `runRevealGame`.

**Tech Stack:** ES5 classic scripts on `window.FF`, no build step, Node test harness (`tools/test/harness.js`), `node tools/serve.js` preview on port 8960.

**Spec:** `docs/superpowers/specs/2026-11-09-charades-design.md`

## Global Constraints

- ES5 only (`var`, `function`, no arrow functions or template strings) in `js/`. Tests may use modern Node.
- Strings via `FF.t(key, fallback)`, with keys prefixed `ch`. Sentence case, no emoji in buttons.
- Colours: theatre colours are custom properties on `.ch-shell` only (`--ch-velvet`, `--ch-curtain`, `--ch-curtain-deep`, `--ch-gold`, `--ch-gold-hi`, `--ch-ink`, `--ch-ink-soft`, `--ch-glass`, `--ch-line`). Never inject `<style>`. Inline styles only for computed geometry or data colours (team colours).
- Copy GeoSpin's look into `ch-` classes. Never use `gs-` classes in Charades.
- Respect reduced motion and the animations setting (copy GeoSpin's `animationsOn()`).
- No card text may be visible before **I'm ready** is pressed, or in any `alt`/`aria-label` outside the acting screen.
- Acting buttons are at least 72 px tall on phones. Nothing scrolls while acting at 375×667.
- Points: guessed 1, guessed with a twist 2, passed 0. Passes are free.
- Setup key `charades:setup:v1`. Defaults `{ decks: ['mix'], level: 'normal', seconds: 60, turns: 1, twists: false }`.
- Bible deck is part of Mixed.
- Work in the worktree `…/scratchpad/wt` on branch `feat/charades`. Never run git merge, checkout or stash in the OneDrive checkout.

## Review Focus

- **Two players, one team each, or a team with nobody in it:** play still works. Empty teams are skipped, and a game with one usable scorer acts as a group high score. → `turnOrder` tests in Task 1.
- **Timer ends mid-card:** that card is recorded as passed, never lost or double counted. → `Turn.timeUp` test in Task 1.
- **A deck pool smaller than a long game:** the dealer reshuffles instead of returning `undefined`. → dealer test in Task 1.
- **An old or garbage saved setup** (unknown deck id, `seconds: 45`, `decks: []`): sanitize falls back per field. → sanitize test in Task 1.
- **Leaving the game mid-turn:** the turn's interval stops (`!wrap.isConnected` check, like the old code), with no sounds or `api.end` after leaving. → browser check in Task 5.

### Task 1: Rules module

**Files:**
- Create: `js/charades/rules.js`
- Test: `tools/test/charades.test.js`

**Interfaces:**
- Consumes: `FF.data.charadesDecks` (Task 2's shape; tests here use a small inline fake deck list).
- Produces `FF.CharadesRules`:
  - `LEVELS = ['easy','normal','hard']`, `SECONDS = [30,60,90]`, `TURNS = [1,2,3]`
  - `LEVEL_TAGS = { easy: ['e'], normal: ['e','n'], hard: ['n','h'] }`
  - `STANDARD = { decks: ['mix'], level: 'normal', seconds: 60, turns: 1, twists: false }`
  - `sanitize(setup, deckIds) -> setup`: per field. `decks` keeps only known ids. Empty, or containing `'mix'`, gives `['mix']`.
  - `pool(decks, setup) -> [{ t, l, deck, kind, signal }]`: `'mix'` = every deck. Filtered by `LEVEL_TAGS[level]`.
  - `Dealer(pool, rand) -> { next() -> card }`: shuffled with `rand`, no repeat until the pool is used up, then reshuffles so the first new card isn't any of the last 5 dealt (when pool > 5).
  - `TWISTS`: 10 `{ id, text }` from the spec (slow motion, one hand only, robot, eyes closed, sitting down, tiptoe, tiny mouse, really angrily, underwater, freezing).
  - `twistFor(rand, prevHadTwist) -> twist|null`: null when `prevHadTwist`, else a twist when `rand() < 0.25`.
  - `points(entry) -> number`: entry `{ got, twist }`.
  - `turnOrder(scorers, turnsEach) -> [{ scorerId, actorId, again }]`: see Step 3.
  - `wordCount(text) -> number`: words split on spaces. A hyphenated word counts once.
  - `Turn(dealer, opts) -> { card(), got(), pass(), timeUp(), flip(i), entries(), score() }`. `opts.twists` is a boolean, `opts.rand` a function. The current card carries `.twist` (or null). `got()`/`pass()` record `{ card, got, twist }` and deal the next. `timeUp()` records the current card as passed and stops dealing. `flip(i)` toggles `got` on entry i. `score()` = sum of `points`.
  - `SIGNALS`: 15 `{ id, name, how }` in spec order (film, book, song, tv, play, saying, words, whichWord, syllables, soundsLike, smallWord, wholeIdea, plural, pastTense, onTheNose).

- [ ] **Step 1: Write failing tests** in `tools/test/charades.test.js`, loading `['js/core.js', 'js/charades/rules.js']` with `loadFF`. Use a seeded rand like `whatsMissing.brain.test.js`'s `seeded()`. Tests:
  - `ch sanitize: bad fields fall back one by one`: `sanitize({ decks: ['nope'], level: 'x', seconds: 45, turns: 9, twists: 'yes' }, ['animals'])` deep-equals `STANDARD`. `sanitize({ decks: ['animals'], seconds: 30 }, ['animals']).decks` is `['animals']` with seconds 30. `decks: ['animals','mix']` gives `['mix']`.
  - `ch pool: level tags`: with a fake deck of cards tagged e/n/h, easy has only `e`, normal `e`+`n`, hard `n`+`h`. `'mix'` covers every deck. Every card has `deck`, `kind`, `signal` copied from its deck.
  - `ch dealer: no repeats until the pool runs out, then reshuffles`: pool of 12, 12 `next()` calls are unique, the 13th is defined and isn't one of the last 5.
  - `ch twists: about a quarter, never twice in a row`: 4000 cards through a `Turn` with twists on have a twist rate between 0.18 and 0.27, and no two adjacent entries both have a twist.
  - `ch turn: got, pass, time up and flip`: got, got, pass, then `timeUp()` gives 4 entries `[true,true,false,false]`. After `timeUp()` further `got()` is ignored. `flip(2)` makes score 3. A twist entry that is got scores 2.
  - `ch turnOrder: teams alternate, actors rotate, uneven teams wrap`: teams A `[a1,a2,a3]` and B `[b1,b2]` with turnsEach 1 give 6 turns, A,B,A,B,A,B, actors a1,b1,a2,b2,a3,b1 with `again` true only on the last. An empty team C is skipped. Individuals (scorers without `players`) act as themselves: `actorId === scorerId`, turnsEach 2 gives each 2.
  - `ch wordCount`: `'The Lion King'` is 3, `'Spider-Man'` is 1, `'  Noah’s  Ark '` is 2.
  - `ch signals: 15 with name and how`.
- [ ] **Step 2:** Run `node tools/test/one.js charades` (or `node tools/test/run.js`). Expected: FAIL, `CharadesRules` undefined.
- [ ] **Step 3: Implement `js/charades/rules.js`.** Use the classic header comment style. `turnOrder`:
  ```
  live = scorers with players.length > 0 (team) or with no players field (individual)
  per = max(live sizes, individuals count as 1) * turnsEach
  for r in 0..per-1: for each live scorer s: idx = r % size(s); actor = s.players ? s.players[idx] : s.id
      push { scorerId: s.id, actorId: actor, again: r >= size(s) * turnsEach }
  ```
  Use `rand` only through the passed function (no `Math.random` inside the deal).
