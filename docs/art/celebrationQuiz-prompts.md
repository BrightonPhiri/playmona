# Celebrations Quiz: Codex prompt pack

One cover for the **Quiz** in Celebrations ("Who Knows {name} Best?"). The prompt
was given in chat on 2026-11-21; the raw file goes in
`assets/playmona_assets/celebration-quiz/cover.png` (git ignores it), then
`python tools/process-game-art.py celebrationQuiz` makes
`assets/images/covers/celebrationQuiz.webp`.

The cover: a glossy gold 3D question mark above a game-show podium, four
blank answer buttons (one glowing green as the right answer), team-coloured
phones, a teal-to-aqua gradient with gold confetti, no text anywhere, the
subject in the middle 40 percent of the height.
